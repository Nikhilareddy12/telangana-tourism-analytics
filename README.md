# Telangana Tourism Analytics

A data analytics project analyzing Telangana tourism trends using **Python, Pandas, MySQL, and Power BI**. The project explores yearly, monthly, and district-wise tourism patterns and identifies growth and recovery trends to support data-driven tourism planning.

## 📌 Project Overview

This project analyzes Telangana tourism data from **2014 to 2024** to uncover key patterns in visitor numbers across years, months, and districts.

The analysis focuses on:
- Yearly tourism trends
- Monthly and seasonal tourism patterns
- District-wise tourism performance
- Year-over-year tourism growth
- Post-pandemic tourism recovery

## 🛠️ Tools & Technologies

- **Python** – Data analysis and exploration
- **Pandas** – Data cleaning, transformation, and aggregation
- **MySQL** – Data storage and SQL-based analysis
- **Power BI** – Interactive dashboard and visualization
